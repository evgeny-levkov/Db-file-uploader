# Приложение для работы с базой данных

Простое desktop-приложение на PyQt6 для подключения к PostgreSQL и вставки данных.

## Функционал

- Подключение к базе данных PostgreSQL
- Проверка соединения
- Вставка данных 

## Требования

- Python 3.8+
- PostgreSQL
- Установленные зависимости (см. ниже)
